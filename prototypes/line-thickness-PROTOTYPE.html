Should a Line be thin or solid?

You set two Anchors and the mod works out the Line: the blocks you place to build between them. A thin Line places one block per step along its longest direction, so neighbouring blocks may touch only at an edge or a corner (marked with red dots). A solid Line adds blocks wherever it needs to, so every block shares a full face with the next and there are no gaps. Compare them on real angles below. Drag a view to rotate it; both views turn together.

Thin

One block per step. Fewest blocks, but gaps at the corners.

Solid

Every block shares a face with the next. No gaps, but chunkier.
