# Changelog

All notable changes to Protractor are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

The release workflow publishes the newest `## [x.y.z]` section as the release notes.

## [0.2.0] - 2026-11-20

First public release.

### Added

- The Protractor item. Craft it from glass panes, tinted glass and glass.
- Right-click sets two Anchors. The mod shows every block of the straight Line between them, at any angle.
- Sneak + right-click cancels a pending Anchor or deletes the Target. Sneak + double right-click clears the dimension's Lines.
- The Measurement HUD: block count, blocks left, distance, deltas, bearing, elevation, X:Y:Z ratio and a ruler of Runs.
- Snap (hold `Left Alt`) snaps the second Anchor to whole-block ratios.
- Lines are saved per world or server and per dimension. A Hide/Show keybind is included.
- `config/protractor.json` for reach, draw distance, colours and snap limits.
